# Tea Cozy ☕

A responsive-style, single-page website built as part of the **Codecademy Front-End Engineer Career Path**.

This project focuses on recreating a provided website design using HTML and CSS, with an emphasis on CSS Flexbox, page layout, and visual styling.

## Project Overview

Tea Cozy is a fictional tea shop website featuring a navigation header, mission statement, featured tea products, store locations, and contact information.

The goal was to recreate the provided design while strengthening my understanding of HTML structure and CSS layout techniques.

## Technologies Used

- **HTML5** — Semantic structure and content
- **CSS3** — Styling, spacing, and page layout
- **CSS Flexbox** — Alignment and positioning of elements
- **Git & GitHub** — Version control and project hosting
- **Chrome DevTools** — Inspecting and debugging layouts

## Features

- Fixed navigation header with working anchor links
- Mission section with a background image
- Featured tea gallery displaying five products
- Three store location cards arranged using Flexbox
- Contact information and copyright footer
- Custom imagery and styling adjustments

## What I Learned

Through this project, I gained hands-on experience with:

- Structuring a webpage using semantic HTML elements
- Using Flexbox to align and distribute content
- Working with the CSS box model, including margins and padding
- Positioning elements using fixed headers and section layouts
- Applying background images and controlling element dimensions
- Debugging visual layout issues using Chrome DevTools
- Using Git to track changes and GitHub to manage project files

## Running the Project Locally

1. Clone the repository:

   `git clone git@github.com:Kbuck2290/tea-cozy.git`

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser, or use the VS Code Live Server extension.
